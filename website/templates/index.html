Traceable preparation of water-quality measurements

LimitAware turns a Water Quality Portal result export into a canonical table, grouped analysis inputs with explicit censoring, and an audit record — before any censored-data estimator is applied.

Living website. The evaluated software release is the immutable archive, not this website. This site runs the same installed package as a demonstration.

What it does

Applies documented WQX vocabulary and a versioned JSON policy per row; preserves limit roles, fractions, methods and refusals; writes per-group analysis files and provenance.

What it does not do

It does not estimate concentrations, rank policies, or claim regulatory or clinical authority. It is a preparation layer for NADA, EnvStats, ProUCL or similar tools.

Upload a supported WQP result CSV (≤2 MB) or load the included example and inspect eligible, excluded and unresolved rows.
